************
User support
************

There are a few ways to ask for help or give feedback:

* `Forum at google groups <https://groups.google.com/g/wulfric>`_

  You may send an email directly to wulfric@googlegroups.com
  This is a preferred channel for the discussions about the user experience and questions.

* `Github discussions <https://github.com/adrybakov/wulfric/discussions>`_

  You may need to create an account at GitHub to post a question.
  This is a preferred channel for the discussions about the development of the project.

Choose the one you prefer.

If you've found a bug or want to request (or discuss) a new feature,
then consider posting an `issue on github <https://github.com/adrybakov/wulfric/issues>`_

* :ref:`contribute_bug`.
* :ref:`contribute_feature`.

If the aforementioned options are not suitable for you, then you can always contact the
|Author|_ directly.
