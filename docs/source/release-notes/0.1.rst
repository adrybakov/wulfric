***********
Version 0.1
***********

0.1.2
=====

Rename :py:func:`.Kpoints.coordinates` to :py:func:`.Kpoints.ticks`. Both
methods are available until version 0.3.0. Deprecation warning is printed every
time :py:func:`.Kpoints.coordinates` is used.


0.1.1
=====

Bugfix for Matplotlib imports. The imports were not shielded, thus if
matplotlib was not installed in the user's environment, the execution would
fail. Plotly imports were already shielded.

0.1.0
=====

First release of Wulfric.
